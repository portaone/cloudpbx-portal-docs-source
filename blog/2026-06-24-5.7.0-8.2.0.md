Releases 8.2.0, 7.4.0, 6.5.0 and 5.7.0 enable **voice AI agents** in the portal. The same functionality has been delivered to all four product lines, so every customer running **MR120** or later can now configure voice AI agents for their extensions.

Minimal PortaSwitch version is **MR120**.

### Enhancements:
- ICAP-2929: Voice AI agent integration on extensions — assign a voice AI agent to an extension, assign the phone number the agent answers on, and initialize the AI tenant session

<!--truncate-->

Users can now pick a voice AI agent for an extension and assign the phone number the agent answers on. The portal initializes the AI tenant session for the company automatically, so no separate onboarding step is required before the first agent is assigned.

 - MR122+: latest portal version is 6.5.0
 - MR124+: latest portal version is 7.4.0
